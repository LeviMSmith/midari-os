# midari-os

**This is nowhere near functional and I have no idea what I'm doing. Probably don't use this for anything unless you're curious.**

midari-os aims to be a minimally functional operating system capable of running on real modern hardware. Currently the [Raspberry PI zero 2 w](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/) is the main hardware target.
